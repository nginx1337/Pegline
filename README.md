**Pegline** — небольшое приложение для macOS, которое держит свежие скриншоты под рукой.

Вы делаете снимок экрана как обычно (⇧⌘4 или ⇧⌘3), и он сразу появляется у верхнего края экрана маленькой фотографией — будто повешен прищепкой на бельевую верёвку. Оттуда его можно отправить в чат, вставить в документ или сохранить в папку, не открывая Finder и не ища файл на рабочем столе. Когда верёвка не нужна, она сама прячется.

**Что можно сделать с фото на верёвке:**

- **щёлкнуть** — картинка скопируется, её можно сразу вставить (⌘V) куда угодно;
- **щёлкнуть дважды** — откроется в «Просмотре»;
- **нажать и подержать** — откроется системная «Разметка»: подписать, обвести, закрасить;
- **перетащить** — в Telegram, браузер, редактор или любую папку;
- **правый щелчок** — меню: показать в Finder, сохранить копию, убрать с верёвки.

Снимки, сделанные сразу в буфер обмена (⌃⇧⌘4), тоже попадают на верёвку, а в режиме «Любые скопированные изображения» — и картинки, скопированные, например, из Telegram. Чтобы снова её увидеть, задержите курсор у самого верха экрана посередине или нажмите ⌃⌥⌘L.

## Сборка

Нужны только Command Line Tools (Xcode не обязателен), macOS 27.

```bash
scripts/build-app.sh            # release → build/Pegline.app
swift test                      # юнит-тесты ядра
```

Установка: перетащите `build/Pegline.app` в «Программы» и откройте.

## Безопасность и приватность

Pegline не использует сеть: снимки и их список остаются на этом Mac, а секреты из менеджеров паролей в буфере обмена не читаются. Подробно — в [SECURITY.md](SECURITY.md), там же написано, как сообщить об уязвимости.

## Как устроено

| Часть | Где |
|---|---|
| Логика без UI: раскладка, классификация файлов, коллекция, проверка «файл дописан» | `Sources/PeglineCore` (+ тесты) |
| Обнаружение: FSEvents по папке снимков + Spotlight (`kMDItemIsScreenCapture`) как страховка | `Sources/Pegline/Detection` |
| Хранилище ссылок на файлы (с закладками, чтобы следить за переименованием) | `Sources/Pegline/Model` |
| Верёвка: прозрачная неактивирующая `NSPanel` + Core Animation | `Sources/Pegline/Line` |
| Меню в строке меню, контекстное меню | `Sources/Pegline/Menu` |
| Настройки и знакомство (SwiftUI) | `Sources/Pegline/Settings`, `Onboarding` |
| Изменения системного инструмента только по согласию, с восстановлением | `Sources/Pegline/System/SystemScreenshotSettings.swift` |

Покачивание — аддитивные анимации Core Animation, их считает системный рендер-сервер: при показанной верёвке процесс почти не тратит процессор, а скрытая верёвка убирается с экрана целиком.

## Ограничения

- **Снимки в буфер обмена** (⌃⇧⌘4 или «Буфер обмена» в ⇧⌘5) тоже попадают на верёвку: Pegline сохраняет их в `~/Pictures/Pegline` и вешает. В macOS нет уведомления об изменении буфера, поэтому раз в 0,4 с проверяется только его счётчик изменений (одно число). Данные читаются, лишь когда там появилась картинка. При первом чтении macOS спросит, можно ли Pegline вставлять из других программ; ответ можно поменять в Системных настройках → Конфиденциальность → Вставка. Пока системный запрос на экране, Pegline ждёт ответа. Скриншот отличается от картинки, скопированной из браузера или редактора, по набору данных: у снимка в буфере только изображение. Режим «Любые скопированные изображения» вешает и такие картинки, а файлы изображений, скопированные в Finder, вешаются как есть, без копии. Telegram, «Сообщения» и «Фото» кладут в буфер ссылку на файл в своей закрытой папке, которую другим программам читать нельзя, — тогда берётся сама картинка, лежащая рядом в буфере. Картинки из временных папок сохраняются копией, а у скопированных папок и документов иконка на верёвку не попадает. Копия больше чем 8 файлов за раз (обычное копирование папки снимков в Finder) пропускается целиком. Файлы в `~/Pictures/Pegline` Pegline сам не удаляет.
- **Плавающая миниатюра macOS** задерживает сохранение файла примерно на 5 секунд. Её можно отключить из Pegline (с подтверждением; при выходе всё возвращается).
- **«Разметка»** открывается через системное расширение `com.apple.MarkupUI.Markup` (то же, что в Finder). Если macOS его не предложит, снимок откроется в «Просмотре», где есть те же инструменты. Если расширение вернёт отдельный результат, он сохранится рядом с оригиналом как «… — разметка.png»; оригинал не перезаписывается.
- **Ваш выбор в ⇧⌘5 важнее.** Если вы сами поменяли папку сохранения или плавающую миниатюру, пока Pegline ими управлял, он не откатывает это при выходе и перестаёт управлять этим параметром.
- **После аварийного завершения** изменённые системные параметры остаются до следующего запуска Pegline; исходные значения при этом сохранены и вернутся при обычном выходе или кнопкой «Вернуть исходные настройки».
- Приложение **не в песочнице**: ему нужно читать настройки `com.apple.screencapture` и следить за выбранной папкой. Подпись — ad-hoc; после каждой пересборки macOS заново спросит доступ к «Рабочему столу». Для распространения подпишите Developer ID и нотарифицируйте.

## Отладка

```bash
log stream --predicate 'subsystem == "app.pegline"'
scripts/build-app.sh debug && build/Pegline.app/Contents/MacOS/Pegline --render-preview out.png dark 6 a.png b.png   # рендер верёвки в PNG (только отладочная сборка)
scripts/build-app.sh debug && PEGLINE_SELFTEST=1 build/Pegline.app/Contents/MacOS/Pegline  # самопроверка
```
