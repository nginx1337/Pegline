# Безопасность и приватность Pegline

## Что Pegline делает с вашими данными

- **Всё остаётся на Mac.** В приложении нет сетевого кода, аналитики, телеметрии и учётных записей.
- **Ссылки, а не копии.** Список снимков на верёвке (`~/Library/Application Support/Pegline/line.json`) хранит только пути и закладки на файлы. Файл и папка доступны лишь вашему пользователю (права `600` и `700`).
- **Буфер обмена.** Pegline раз в 0,4 с проверяет только счётчик изменений. Данные читаются, лишь когда там появилась картинка нужного вида. Содержимое с пометками «секрет» или «временное» по соглашению [nspasteboard.org](http://nspasteboard.org) (их ставят менеджеры паролей) не читается и не сохраняется. Картинки из буфера сохраняются в `~/Pictures/Pegline` с доступом только для вас.
- **Недоверенные картинки.** Данные из буфера и скопированные файлы перед декодированием проверяются по размеру (до 300 МБ) и числу пикселей (до 250 Мп). Данные, которые только называют себя картинкой, отбрасываются.
- **Системные настройки.** Параметры инструмента «Снимок экрана» меняются только после подтверждения в диалоге и возвращаются при выходе. Изменения, которые вы сделали сами в ⇧⌘5, Pegline не откатывает.
- **Журнал.** Имена файлов и пути в системном журнале скрыты (`privacy: .private`).
- **Мышь и клавиатура.** Pegline отслеживает только положение курсора, чтобы показывать верёвку, и никуда его не записывает. Нажатия клавиш читаются лишь в окне настроек, пока вы записываете сочетание. Глобальное сочетание регистрируется через системный механизм горячих клавиш, без доступа к универсальному доступу.

## Разрешения

| Разрешение | Зачем |
|---|---|
| Доступ к папке «Рабочий стол» (или другой папке снимков) | Видеть новые скриншоты |
| Вставка из других программ (при первом снимке в буфер) | Вешать снимки, сделанные в буфер обмена |

Запись экрана, универсальный доступ и полный доступ к диску **не нужны**.

## Сборка и подпись

- Приложение собирается с hardened runtime и без entitlements.
- Сторонних зависимостей нет.
- Песочницы нет: Pegline должен читать настройки `com.apple.screencapture` и следить за выбранной папкой.
- Отладочные режимы (`--render-preview`, самопроверка через переменные `PEGLINE_*`) есть только в отладочной сборке и в релиз не попадают.
- Сборка из репозитория подписана ad-hoc. Для распространения нужна подпись Developer ID и нотаризация.

## Как сообщить об уязвимости

Не публикуйте подробности в открытых issues. Воспользуйтесь закрытым сообщением об уязвимости на GitHub (вкладка **Security → Report a vulnerability**). Опишите шаги воспроизведения и версию macOS.
